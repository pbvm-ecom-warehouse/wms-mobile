# Workflow Rules

- Đọc `codex.md` và các rule liên quan trước khi sửa code.
- Kiểm tra implementation hiện có trong `src/` trước khi thêm mới.
- Ưu tiên thay đổi nhỏ nhất nhưng đúng chức năng.
- Trước khi kết luận hoàn thành, chạy kiểm tra phù hợp với thay đổi.

## Gợi ý xác minh

- `npm run start`
- kiểm tra TypeScript hoặc lint nếu repo bổ sung script tương ứng sau này

## Nguyên tắc an toàn

- Không xóa file hoặc thay đổi phá hủy mà chưa có yêu cầu rõ ràng.
- Không ghi đè các thay đổi không liên quan của người dùng.
